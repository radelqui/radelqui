## The Sypnose methodology

```
Human Architect (decides) → Service Manager (coordinates) → Architects (execute)
                                    ↕
                        Quality Gate (Gemini validates every plan)
                        Knowledge Hub (shared memory across agents)
                        Boris v6.2 (verification hooks — no evidence, no commit)
```
